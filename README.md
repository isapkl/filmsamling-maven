# Filmsamling - hold 5


Et konsolprogram til at oprette, vise, søge, redigere og slette film.
Programmet kan også registrere, hvornår en film sidst blev set.

## Sådan køres programmet

Projektet bruger Maven og JDK 25.

1. Åbn projektet i IntelliJ IDEA.
2. Indlæs Maven-afhængighederne fra pom.xml.
3. Åbn src/main/java/Main.java.
4. Klik på den grønne pil ved main-metoden.
5. Følg menuen i konsollen.

## Implementerede funktioner

- Opret, vis, søg, redigér og slet film.
- Markér en film som set på en bestemt dato.
- Find film, der ikke er set længe, eller aldrig er set.
- Validering af filmoplysninger og håndtering af forkert input.
- Vis film sorteret efter titel, genre, instruktør, længde eller årstal.
